# 見た目と言葉の決まり

mado の画面は、denpa の [見た目の決まり](https://github.com/danything/denpa/blob/main/docs/design.md)と[書き方](https://github.com/danything/denpa/blob/main/docs/writing.md)に揃える。
合言葉も同じ: **塗らない。囲みすぎない。浮かせすぎない。でも、ちゃんと伝わる。**
mado は Blades CSS(Pico の後継)なので、denpa の CSS は持ってこず、決まりだけを `web/style.css` の `--mado-*` に写している。値は `--mado-*` から選び、画面ごとに新しい値を作らない。

## 当てたもの

| 決まり                       | mado での形                                                                                                                                                                                                                                |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ふだんは平らに               | 接続先の一覧は地に置き、枠も影も付けない                                                                                                                                                                                                   |
| 浮かせるのは動く中身の上だけ | RDP と AMT の操作の 1 行は画面(canvas・SOL の端末)に重ね、denpa のプレーヤーの操作列と同じく、上の端から濃くなる影の上に塗らないボタンを置く。触らなければ 2.5 秒で引っ込む(`web/autohide.ts`)。メニューと診断は暗い面で透かす(ぼかさない) |
| 選んでいるものは線と太字     | 接続先の一覧は、左の縦線と主の色の太字。行は塗らない。丸いラジオは見せない(読み上げとキーボードには残す)                                                                                                                                   |
| 事実はバッジにしない         | 種類(RDP / AMT・電源と SOL)は控えた字で添える                                                                                                                                                                                              |
| ボタンの強弱は層と太さ       | 主(接続・開く)は操作の層の面と影のカプセルで太字。控えは平らで、乗せたら薄い地。戻せない操作(リセット・電源の入れ直し・強制電源オフ・証明書の置き換え)は、乗せたときと確定で赤い字(塗らない)                                               |
| 浮いたものの中では浮かせない | ダイアログの中のボタンは太字だけ                                                                                                                                                                                                           |
| 入力欄は平らな面だけ         | 線も凹みも無い薄い面。打っている間と焦点は外側の 2px の主の色の線                                                                                                                                                                          |
| 通知はアイコンと言葉         | 状態の文は頭の ✕ / ✓ / ⚠ にだけ状態の色を使い、字は本文の色。ダイアログの危ないときは見出しの頭の ⚠ を赤く(面も縁も赤くしない、左の線も引かない)                                                                                           |
| 色は役目ごと                 | 主の色(藍)は線・焦点・リンク・淡い光、緑は「オン」「接続中」の点、赤は危ない操作の字とアイコン                                                                                                                                             |
| 見せる画面は一歩出てよい     | ログインの前の画面は、地に主の色の淡い光(`radial-gradient`、動かさない)                                                                                                                                                                    |
| 舞台はテーマで変えない       | RDP の画面と SOL の端末はいつも黒い                                                                                                                                                                                                        |
| 動きは CSS で軽く            | 時間と曲線は `--mado-duration*` と `--mado-ease*`。ダイアログは `@starting-style` でばねで出る。主のボタンは押すと 97% に縮む。動きを減らす設定では 0 にする                                                                               |
| 日本語は文節で折り返す       | `word-break: auto-phrase`、段落は `text-wrap: pretty`                                                                                                                                                                                      |
| ボタンは体言止め             | 接続・切断・更新・取消・電源オン・リセットなど。閉じる・開くは動詞のまま                                                                                                                                                                   |
| 画面の文はです・ます、短く   | 「接続できませんでした」「AMT のユーザー名かパスワードが違います」など。サーバーが返す文も同じ                                                                                                                                             |

## 当てていないもの

- 3 つの層のうち「件の面」: mado には 2〜3 行ある一覧が無い
- ヘッダーを巻いた量で浮かせる、下のタブ、スマホの形: mado の画面は巻かない 1 枚で、ナビゲーションも無い
- 選んでいる印が滑る動き(アンカー): 一覧が短く、線は透明度で出し入れするだけにした
- `data-lite`(ソフトウェアで描いている端末で止める): 時間で動き続けるものが無い
- コードのコメントと既存の docs の言葉(「道」「版」「頼む」など)は、画面の文言だけを直し、ほかはまだ直していない
